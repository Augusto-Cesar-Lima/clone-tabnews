Repositório criado para registrar meu progresso no **[curso.dev](https://curso.dev)**, curso de programação do **Filipe Deschamps**.

## 🎯 Sobre o curso

O curso tem como base a reconstrução do **TabNews** — um projeto real com mais de 180.000 acessos mensais. O objetivo é desenvolver senioridade através de prática real, não projetos fictícios.

## 🛠️ Tecnologias praticadas

- **Controle de versão:** Git, GitHub, Conventional Commits
- **Linguagem e runtime:** JavaScript, Node.js, NPM
- **Front-end:** React, Next.js, SWR
- **Qualidade de código:** ESLint, Prettier, EditorConfig
- **Testes:** Jest, testes automatizados
- **Banco de dados:** PostgreSQL, Docker, Migrations
- **CI/CD:** Integração e deploy contínuo

## 📖 O que estou aprendendo

- Boas práticas de desenvolvimento profissional
- Como estruturar projetos reais do zero
- Colaboração em equipe com Pull Requests e Code Review
- Construção de sistemas robustos e escaláveis
